# 方方詞卡

iPhone／iPad 的台語單詞卡 App。像交友 App 一樣滑卡片：

- **往右滑 = 認識** → 放進「熟悉」
- **往左滑 = 不熟** → 放進「不熟」，可以練習

卡片顯示漢字、皓羅（可切換台羅／白話字）、方音、白／文標示、釋義、例句和發音。詞按照常用程度排列（依教育部辭典例句裡出現的次數）。

## 安裝

需要：Mac + Xcode（已經登入你的 Apple ID），iPhone／iPad 已經開過開發者模式。

1. 解壓縮到「下載項目」（或從 GitHub 下載／clone）。
2. iPhone 解鎖，接上傳輸線（或跟 Mac 連同一個 Wi-Fi）。
3. 打開 Terminal，執行：

```
bash ~/Downloads/fangfang-cards/install.sh
```

它會自動建置 App，安裝到所有找得到的 iPhone／iPad，**也會裝一份到 Mac**（「應用程式」資料夾裡的「方方詞卡」）。

- 只裝手機／平板：`install.sh ios`；只裝 Mac：`install.sh mac`
- 免費 Apple ID：iPhone／iPad 版 **7 天後再執行一次同一個指令**就好。Mac 版只在你自己的 Mac 上執行，不會過期。
- 第一次執行時，如果專案裡還沒有詞典資料，它會自動從教育部網站下載 `kautian.ods` 再整理成 App 用的資料（見下面「詞典資料」）。

專案會放在家目錄的 `FangfangCards` 資料夾。想用 Xcode 打開也可以：雙擊 `~/FangfangCards/FangfangCards.xcodeproj`，上方選你的 iPhone 或「My Mac」，按 ▶。

### Mac 版

Mac 版是同一個 App（Mac Catalyst）：分頁會變成側邊欄，「轉換」在寬的視窗會分成左右兩欄（左邊輸入，右邊三種寫法），卡片和詞條頁會維持好讀的寬度。滑卡片可以用滑鼠拖，或按鍵盤 **←**（不熟）、**→**（認識）、**⌘Z**（復原）。

### 詞典資料

App 用的兩個資料檔 `FangfangCards/dict.json` 和 `FangfangCards/cards.json` **不放在 GitHub 上**。它們是從教育部《臺灣台語常用詞辭典》整理出來的，辭典的授權（創用CC 姓名標示-禁止改作）不允許散布改過的版本，所以每個人在自己的電腦上從原始檔案產生：

```
bash build-data.sh                       # 自動下載 kautian.ods
bash build-data.sh ~/Downloads/kautian.ods   # 或用已經下載的檔案
```

需要：Python 3（Mac 上裝了 Xcode 就有）。`install.sh` 找不到資料時會自動執行這一步。

## 功能

| 分頁 | 做什麼 |
|---|---|
| **新詞** | 從最常用的詞開始滑。↺ 可以復原上一張。 |
| **不熟** | 往左滑的詞。按「開始練習」做題目。列表往右滑 → 直接移到熟悉；往左滑 → 移回新詞。 |
| **熟悉** | 往右滑的詞。「卡片複習」可以再滑一次：往左滑的詞會回到「不熟」。 |
| **轉換** | 方方轉換器（App 本身的畫面）：漢字 ⇄ 皓羅 ⇄ 方音，也讀台羅／白話字。點輸出的詞可以換讀音（會記住）、看辭典解釋、收藏、加到「不熟」。也可以把整段的新詞一次加到「不熟」或收藏。 |
| **詞典** | **查詞**：查華語詞、各地講法；用 * 和 ? 找台語詞（人* = 人開頭、*仔 = 仔結尾、*水* = 水在中間、?仔 = 兩個字仔結尾）。**分類**：教育部辭典的 199 個分類，每個分類的詞照常用程度排，可以一次把新詞加到「不熟」。**收藏**：收藏的詞，可以匯出 CSV。列表裡往右滑 = 加到「不熟」，往左滑 = 收藏。 |
| **⚙︎ 設定**（每個分頁右上角） | 羅馬字、腔口、隱藏意思、自動播放、音量、練習設定、匯出 CSV、備份、匯入。 |

**捷徑（Shortcuts）**：捷徑 App 裡有兩個方方詞卡的動作。
- **在方方詞卡查詞**：輸入一個詞（華語、台語漢字、羅馬字或方音），打開 App 的「詞典」查這個詞。在那裡可以聽發音、收藏（收藏可以匯出 CSV）、加到「不熟」。
- **方方快速查詞**：不打開 App，直接回傳漢字、讀音和意思（文字），可以接到其他捷徑動作。
也可以跟 Siri 說「在方方詞卡查詞」，或把它放到主畫面、動作按鈕、分享選單（搭配「要求輸入」或「從輸入取得文字」）。

**練習題型**：看意思選台語詞、看台語詞選意思、聽發音選詞、例句填空、看漢字選讀音。連續答對 3 次（可以改）就學會，自動移到「熟悉」。

**聲調練習**（「不熟」分頁）：看漢字、聽發音，從幾個只有聲調不一樣的拼法裡選出正確的。一定會出現容易搞混的那一個（皓羅：1↔8、3↔4；台羅／白話字：1↔4）。答完會顯示每個選項是第幾聲。多音節的詞只換最後一個字的聲調。先用不熟的詞，再用常用詞。

右上角的「皓羅」按鈕點一下就換成台羅 → 白話字 → 皓羅。

**腔口**（設定）：通行，或鹿港、三峽、臺北、宜蘭、臺南、高雄、金門、馬公、新竹、臺中。卡片會顯示那個地方的讀音（有資料的詞），方音的 ㄛ／ㄜ 也跟著調整。例句裡的詞也會換成那個地方的讀音：App 用漢字和羅馬字的連字號（-）找出句子裡的每個詞，辭典裡有那個地方讀音的詞就換掉，其他的照原本的通行讀音。

**主題**（「新詞」左上角）：照教育部辭典的分類滑卡片，例如「食物、飲料、煙酒」「稱謂輩分」「時間節令」。

詳細頁也會顯示其他讀音（又／俗／合）、近義詞、反義詞和分類。

iOS 26 上卡片、按鈕和選項都是 Liquid Glass，往右／往左拖卡片時玻璃會變成綠色／紅色。設定裡可以關掉。

## 進度與備份

- 進度存在 App 裡面。重新安裝（執行 install.sh）不會清掉進度；把 App 刪掉才會。
- **自動備份**：設定 → 自動備份 → 選擇備份資料夾（建議 iCloud Drive 裡開一個「方方詞卡」資料夾）。之後每次打開和離開 App 都會自動備份，每天另存一份到「方方詞卡舊備份」（保留 14 天）。
- **iPhone ↔ iPad 同步**：兩台都選同一個資料夾。每台寫自己的備份檔，打開 App 時會讀另一台的檔案，同一個詞以比較新的變更為準。
- **手動備份**：設定 → 備份檔分享／另存，在另一台裝置 **匯入備份**。
- **匯入方方收藏**：選方方網站或 Safari 擴充功能匯出的備份檔，收藏的詞會加到「不熟」。
- **匯出 CSV**：跟方方網站的收藏 CSV 一樣（分號分隔，九欄），可以匯入 Anki。

## 放到 GitHub

這個資料夾就是可以直接放上 GitHub 的樣子：

- `.gitignore` 會排除詞典資料檔（`dict.json`、`cards.json`、`*.ods`）和 Xcode 的個人設定。
- `FangfangCards.xcodeproj` 裡的 `DEVELOPMENT_TEAM`（Apple 開發者團隊 ID）是空的；`install.sh` 會自動從你的 Xcode 帳號找出來，存在 `~/.fangfang-team`。
